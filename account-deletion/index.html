Inbox 계정·게스트 데이터 삭제

시행일: 2026-09-25
최종 개정일: 2026-09-25

본 페이지는 모바일 애플리케이션 Inbox(개발자: Seungyong)의 연결 계정 또는 게스트 데이터 삭제를 요청하는 방법을 안내합니다.

계정 삭제 방법

방법 1 — 앱에서 직접 (권장)

  1. Inbox 앱을 실행합니다.
  2. 설정을 엽니다.
  3. 아래쪽 위험 구역 → 계정 삭제를 선택합니다.
  4. 안내를 확인하고 “삭제”를 입력합니다.
  5. 계정 삭제 요청을 선택합니다.

요청이 접수되면 즉시 로그아웃되고 계정 접근이 차단됩니다. 계정·콘텐츠·첨부 파일의 물리 삭제는 즉시 시작되며 최대 24시간 안에 완료됩니다. 삭제된 데이터는 복구할 수 없습니다.

방법 2 — 이메일로 요청

앱을 사용할 수 없는 경우 아래 연락처로 삭제를 요청할 수 있습니다. 연결 계정이 있으면 연결한 이메일 주소를 알려주세요. 게스트로만 사용했고 세션을 잃은 경우에는 회사가 이메일이나 Apple 앱 identity만으로 해당 메모의 소유권을 확인하거나 복구·삭제 대상을 특정하지 못할 수 있습니다.

  • 이메일: pri1038@naver.com

삭제되는 데이터

게스트 또는 연결 계정 데이터 삭제 시 해당 이용자 UUID에 속한 다음 데이터를 삭제합니다.

  • 인증 정보
  • 저장한 모든 노트 (제목·요약·원문·태그·카테고리)
  • 첨부한 이미지 및 파일
  • 카테고리·태그 및 앱 설정

보관되는 데이터 및 기간

  • 삭제 요청 시 이용자 접근은 즉시 차단되고, 계정과 콘텐츠의 물리 삭제는 최대 24시간 안에 완료됩니다.
  • 회사는 삭제된 콘텐츠를 복구 목적으로 30일간 별도 보관하지 않습니다.
  • 완료된 삭제 작업 상태와 복구 영수증 해시는 삭제 완료 확인과 제한적 장애 대응을 위해 완료 후 최대 30일 보관합니다. 콘텐츠는 포함하지 않습니다.
  • Apple 거래의 최소 가명 기록은 관련 법령상 보존 의무 이행을 위해 이벤트별 최대 5년 보관될 수 있습니다. 이메일, Inbox 사용자 ID, 메모·첨부 콘텐츠는 포함하지 않으며 계정 복원·마케팅에 사용하지 않습니다.
  • 무료 10회의 중복 재지급을 막기 위해 가명 Apple 앱 identity digest와 무료 성공 횟수는 무료체험 제도가 운영되는 동안 서비스 계약 이행과 중복 재지급 방지 목적으로 분리 보관하고, 제도 종료 시 삭제합니다. 이메일, 원본 Apple identity, 메모·첨부는 포함하지 않으며 콘텐츠 복구·광고·마케팅·추적에 사용하지 않습니다.
  • 계정 연결·이전 복구·보안 확인 기록은 계정 이전 또는 취소에 따른 복사본 정리가 완료될 때까지 사용하고, 완료·취소된 작업의 기록은 복사본 정리 완료 확인 후 최대 30일 안에 삭제합니다. 이는 원문 콘텐츠를 30일간 별도 보관한다는 뜻이 아닙니다. 유료권한 연결에 필요한 최소 기록은 기존 유료 이용·복원 기록의 보유 기준에 따릅니다.

Apple 구독은 별도로 해지해야 합니다

Inbox 계정을 삭제해도 Apple App Store의 자동 갱신 구독은 취소되지 않습니다.

  • iOS 설정 → Apple 계정 → 구독 또는 Apple 구독 관리에서 별도로 해지할 수 있습니다.
  • 환불은 Apple 환불 요청 절차를 이용합니다.
  • 구독을 먼저 해지하지 않아도 계정 삭제를 요청할 수 있습니다.
  • 구매 복원은 현재 검증 가능한 월간·평생 이용권만 다시 확인합니다. 삭제된 데이터, 접근할 수 없는 메모·첨부 또는 잃어버린 게스트 세션은 복원하지 않습니다.
